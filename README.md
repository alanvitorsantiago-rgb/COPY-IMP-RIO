## ⚙️ Como rodar localmente

```bash
# 1. Clone o repositório
git clone https://github.com/alanvitorsantiago-rgb/COPY-IMP-RIO.git
cd COPY-IMP-RIO

# 2. Instale as dependências
npm install

# 3. Configure as variáveis de ambiente
cp .env.example .env
# Edite o .env e adicione sua chave da Anthropic

# 4. Rode o projeto
npm run dev
```

## 🌐 Como publicar (Deploy)

### Vercel (recomendado — gratuito)
1. Crie conta em [vercel.com](https://vercel.com)
2. Importe este repositório do GitHub
3. Adicione a variável `VITE_ANTHROPIC_API_KEY` nas configurações
4. Clique em **Deploy** ✅

### Netlify
1. Crie conta em [netlify.com](https://netlify.com)
2. Arraste a pasta `dist/` (após `npm run build`) ou conecte o GitHub
3. Configure as variáveis de ambiente
